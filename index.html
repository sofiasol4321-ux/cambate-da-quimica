⚙️ OPÇÕES — COMO JOGAR

🎮 Jogador 1

  • W mover para frente
  • S mover para trás
  • A desferir soco
  • Espaço pular
  • Ctrl agachar
  • Shift ativar Fatality

🎮 Jogador 2

  • ← / → mover
  • ↑ pular
  • ↓ agachar
  • Numpad 0 soco
  • Enter Fatality

🃏 Flash Card / Pergunta

Quando a pergunta aparecer, a luta fica pausada e nenhum movimento, ataque ou Fatality funciona.

  • D ou C = resposta certa
  • E = resposta errada
  • O primeiro comando mostra o verso do Flash Card.
  • Depois do verso, pressione novamente D, C ou E para voltar à luta.

🕹️ Controle / Manete

Se o navegador reconhecer o controle, o jogo tenta utilizar este padrão:

  • D-pad ou analógico esquerdo: ←/→ mover
  • ↓ agachar
  • ↑ pular
  • Botão X: soco
  • Botão A: pular
  • Botão B: agachar
  • Botão Y: Fatality
  • Durante a pergunta: A = certa • B = errada

Os nomes dos botões podem mudar conforme o controle. Se o seu controle usar outra disposição, podemos trocar os comandos no código.

☠️ Fatality

Um Fatality normal só pode ser usado quando a vida do adversário estiver baixa. Se o jogador ganhar um Fatality no Flash Card, ele fica liberado mesmo que a vida do adversário esteja alta. Para executar, pressione o comando de Fatality.
